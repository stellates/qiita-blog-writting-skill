# Qiita Blog Writing Skill

Qiita向けの技術記事の企画・執筆・品質確認に使う、リポジトリや筆者に依存しないAI Skillです。

## できること

- 読者と記事の目的から投稿価値を判断
- 規約・ガイドラインの確認（参照不可時は未確認と報告）
- 変動情報のファクトチェックと一次情報の確認
- 記事全体の論理を反映した見出し設計
- Qiita向けMarkdown（表、コード、note、details、画像）の使い分け
- 完成稿の品質チェックと必要な修正

## 使い方

AIエージェントに [SKILL.md](./SKILL.md) を読み込ませて、記事テーマ、対象読者、伝えたい主張、参考資料を渡してください。対応するSkill機構を持つツールでは、その機構に従って登録してください。

依頼例：

> SKILL.md に従って、○○の検証結果をQiita技術記事にしてください。対象読者は△△です。まず投稿価値と見出し構成を確認し、次に本文を作成してください。

## 見出し設計の基本

- 見出しは本文の単純な要約ではなく、記事全体の論理構造を示す「骨」にする
- `#` は文書タイトル（媒体が管理する場合は省略可能）
- `##` は最上位のセクション、`###` と `####` は意味上の下位区分
- 階層は見た目や分量ではなく、意味上の親子関係で判断する
- 「はじめに」「まとめ」を機械的に追加しない

## 対象外

Qiitaへの自動投稿、ファイルの保存先、GitHub運用、固有のScrap管理、特定の筆者・シリーズの文体や構成は扱いません。
